⚙️ Copilot Studio 챗봇 권한 설정 안내 ("You don't have access" 오류 해결법)
챗봇 창에 "You don't have access to talk to this bot"이라는 메시지가 뜬다면 아래 순서로 Copilot Studio 설정을 변경해 주세요!
  1. Microsoft Copilot Studio (copilotstudio.microsoft.com)에 접속합니다.
  2. 챗봇 편집 화면의 좌측 메뉴에서 [설정 (Settings)] ➡️ [보안 (Security)] ➡️ [인증 (Authentication)]을 클릭합니다.
  3. 인증 옵션을 '인증 없음 (No authentication)' 또는 '공개 (Public)'로 변경합니다.
  4. 상단 [게시 (Publish)] 버튼을 눌러 변경사항을 적용하시면 웹앱에서 누구나 로그인 없이 바로 대화할 수 있습니다!
